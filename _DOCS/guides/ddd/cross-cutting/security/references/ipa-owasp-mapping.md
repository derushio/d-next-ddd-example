# IPA-OWASP-CWE 対応表

## 概要

この対応表は、IPA（独立行政法人情報処理推進機構）が公開している「安全なウェブサイトの作り方」で定義されている11の脆弱性カテゴリと、OWASP Top 10 2021、CWE（Common Weakness Enumeration）の対応関係を整理したものです。

脆弱性の分類体系の違いを理解し、適切な対策を実施するための参考資料として活用してください。

## IPA脆弱性とOWASP/CWE対応表

| IPA番号 | IPA脆弱性名 | OWASP Top 10 2021 | CWE番号 | 説明 | 主な対策 |
|---------|-------------|-------------------|---------|------|----------|
| 1 | SQLインジェクション | A03: Injection | CWE-89 | データベースへの不正なSQL文の実行を許してしまう脆弱性 | プリペアドステートメント、ORM使用、入力値検証 |
| 2 | OSコマンドインジェクション | A03: Injection | CWE-78 | OSコマンドの不正実行を許してしまう脆弱性 | OSコマンド呼び出しの回避、シェルメタ文字のエスケープ |
| 3 | HTTPヘッダインジェクション | A03: Injection | CWE-113 | HTTPレスポンスヘッダに改行文字を挿入され、任意のヘッダやボディを追加される脆弱性 | 改行文字の除去、フレームワークのヘッダ設定機能使用 |
| 4 | クロスサイトスクリプティング（XSS） | A03: Injection | CWE-79 | Webページに悪意のあるスクリプトを埋め込まれる脆弱性 | 出力時のHTMLエスケープ、CSP設定、DOMベースXSS対策 |
| 5 | クロスサイトリクエストフォージェリ（CSRF） | A01: Broken Access Control | CWE-352 | ユーザの意図しない操作を強制される脆弱性 | CSRFトークン、SameSite Cookie、二段階認証 |
| 6 | クリックジャッキング | A05: Security Misconfiguration | CWE-1021 | 透明な iframe により意図しないクリックを誘発される脆弱性 | X-Frame-Options、CSP frame-ancestors ディレクティブ |
| 7 | セッション管理の欠陥 | A07: Identification and Authentication Failures | CWE-384 | セッションIDの盗用、固定化、推測を許してしまう脆弱性 | セッションID再生成、Secure/HttpOnly属性、タイムアウト設定 |
| 8 | 認可制御の欠落 | A01: Broken Access Control | CWE-285 | アクセス制御の不備により権限外の操作を許してしまう脆弱性 | 認可チェック実装、最小権限の原則、デフォルト拒否 |
| 9 | ディレクトリトラバーサル | A01: Broken Access Control | CWE-22 | ファイルパスの操作により意図しないファイルにアクセスされる脆弱性 | パス正規化、ホワイトリスト検証、直接パス指定の回避 |
| 10 | バッファオーバーフロー | A06: Vulnerable and Outdated Components | CWE-120 | メモリ領域外への書き込みにより任意のコード実行を許す脆弱性 | 安全な関数使用、境界チェック、最新ライブラリ使用 |
| 11 | メールヘッダインジェクション | A03: Injection | CWE-93 | メールヘッダに改行文字を挿入され、スパムメール送信等に悪用される脆弱性 | 改行文字の除去、メール送信ライブラリ使用 |

## OWASP Top 10 2021 逆引き表

OWASPカテゴリから関連するIPA脆弱性を逆引きするための表です。

### A01: Broken Access Control

| CWE | 関連するIPA脆弱性 | 説明 |
|-----|-------------------|------|
| CWE-352 | 5. CSRF | ユーザの意図しない操作を強制される |
| CWE-285 | 8. 認可制御の欠落 | 権限外の操作を許してしまう |
| CWE-22 | 9. ディレクトリトラバーサル | 意図しないファイルへのアクセス |

**概要**: アクセス制御の不備により、ユーザが本来アクセスできないリソースへのアクセスや、権限外の操作を許してしまう問題。

### A02: Cryptographic Failures

| CWE | 関連するIPA脆弱性 | 説明 |
|-----|-------------------|------|
| - | （直接該当なし） | 暗号化の不備、弱い暗号アルゴリズム使用 |

**概要**: 機密データの保護に失敗する問題。IPAの11項目には直接該当しないが、セッション管理や認証に関連。

### A03: Injection

| CWE | 関連するIPA脆弱性 | 説明 |
|-----|-------------------|------|
| CWE-89 | 1. SQLインジェクション | 不正なSQL文の実行 |
| CWE-78 | 2. OSコマンドインジェクション | 不正なOSコマンドの実行 |
| CWE-113 | 3. HTTPヘッダインジェクション | HTTPヘッダの不正操作 |
| CWE-79 | 4. XSS | 悪意のあるスクリプトの埋め込み |
| CWE-93 | 11. メールヘッダインジェクション | メールヘッダの不正操作 |

**概要**: 信頼できないデータがコマンドやクエリの一部として送信され、意図しない動作を引き起こす問題。

### A04: Insecure Design

| CWE | 関連するIPA脆弱性 | 説明 |
|-----|-------------------|------|
| - | （直接該当なし） | 設計段階でのセキュリティ考慮不足 |

**概要**: セキュアな設計原則の欠如による問題。脅威モデリングやセキュアデザインパターンの適用不足。

### A05: Security Misconfiguration

| CWE | 関連するIPA脆弱性 | 説明 |
|-----|-------------------|------|
| CWE-1021 | 6. クリックジャッキング | iframe による意図しないクリック誘発 |

**概要**: セキュリティ設定の不備や初期設定のまま運用することによる問題。

### A06: Vulnerable and Outdated Components

| CWE | 関連するIPA脆弱性 | 説明 |
|-----|-------------------|------|
| CWE-120 | 10. バッファオーバーフロー | メモリ領域外への書き込み |

**概要**: 脆弱性を含む古いライブラリやフレームワークの使用による問題。

### A07: Identification and Authentication Failures

| CWE | 関連するIPA脆弱性 | 説明 |
|-----|-------------------|------|
| CWE-384 | 7. セッション管理の欠陥 | セッションIDの盗用・固定化 |

**概要**: 認証機能の実装不備により、なりすましやセッションハイジャックを許してしまう問題。

### A08: Software and Data Integrity Failures

| CWE | 関連するIPA脆弱性 | 説明 |
|-----|-------------------|------|
| - | （直接該当なし） | ソフトウェア更新やデータの完全性検証不足 |

**概要**: 完全性検証なしにソフトウェア更新やデータを扱うことによる問題。

### A09: Security Logging and Monitoring Failures

| CWE | 関連するIPA脆弱性 | 説明 |
|-----|-------------------|------|
| - | （直接該当なし） | ログ記録・監視の不足 |

**概要**: 適切なログ記録や監視の欠如により、セキュリティインシデントの検知や対応が遅れる問題。

### A10: Server-Side Request Forgery (SSRF)

| CWE | 関連するIPA脆弱性 | 説明 |
|-----|-------------------|------|
| - | （直接該当なし） | サーバサイドからの不正なリクエスト送信 |

**概要**: Webアプリケーションが検証なしにユーザ指定のURLへリクエストを送信することによる問題。

## CWE Top 25 との関連

IPAの11脆弱性のうち、CWE Top 25（最も危険なソフトウェア脆弱性）に含まれるものを優先度順に示します。

| 優先度 | CWE | IPA脆弱性 | CWE Top 25 ランク（2023） |
|--------|-----|-----------|---------------------------|
| 高 | CWE-79 | 4. XSS | 2位 |
| 高 | CWE-89 | 1. SQLインジェクション | 3位 |
| 高 | CWE-352 | 5. CSRF | 9位 |
| 高 | CWE-22 | 9. ディレクトリトラバーサル | 8位 |
| 中 | CWE-78 | 2. OSコマンドインジェクション | 7位 |
| 中 | CWE-285 | 8. 認可制御の欠落 | 22位 |
| 中 | CWE-384 | 7. セッション管理の欠陥 | - |
| 低 | CWE-120 | 10. バッファオーバーフロー | - |
| 低 | CWE-113 | 3. HTTPヘッダインジェクション | - |
| 低 | CWE-93 | 11. メールヘッダインジェクション | - |
| 低 | CWE-1021 | 6. クリックジャッキング | - |

## このプロジェクトでの対策状況

本プロジェクトでは、上記脆弱性に対して以下の対策を実装しています。

### 実装済み対策

| IPA脆弱性 | 対策状況 | 実装場所・手法 |
|-----------|----------|----------------|
| 1. SQLインジェクション | ✓ | Prisma ORM使用、型安全なクエリ |
| 2. OSコマンドインジェクション | ✓ | OSコマンド呼び出しの回避 |
| 3. HTTPヘッダインジェクション | ✓ | Next.js標準機能、proxy.ts設定 |
| 4. XSS | ✓ | React自動エスケープ、CSP設定 |
| 5. CSRF | ✓ | Next.js Server Actions（自動保護） |
| 6. クリックジャッキング | ✓ | proxy.ts でX-Frame-Options設定 |
| 7. セッション管理 | ✓ | next-auth、Secure/HttpOnly Cookie |
| 8. 認可制御 | ✓ | UseCase層での認可チェック |
| 9. ディレクトリトラバーサル | ✓ | 直接パス指定の回避、検証処理 |
| 10. バッファオーバーフロー | ✓ | TypeScript/Node.js環境（メモリ安全） |
| 11. メールヘッダインジェクション | ✓ | メールライブラリの安全な使用 |
